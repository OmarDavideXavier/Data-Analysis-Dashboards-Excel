# Excel Data Dashboards – Análise e Visualização de Dados
Este repositório contém dashboards interativos criados com Microsoft Excel, com base em dados simulados que descrevem aspectos reais. 
Cada projeto aqui representa uma jornada completa de análise de dados, desde a coleta e organização até a transformação em insights visuais para apoio à tomada de decisão.

## 📌 Objetivo
Demonstrar na prática como a análise de dados com Excel pode gerar **insights valiosos** para diferentes áreas (vendas, RH, operações, etc.). 
O repositório também serve como portfólio para oportunidades como Analista de Dados ou BI.

## 🧭 Metodologia aplicada
Para criar cada dashboard, segui um processo em 4 etapas fundamentais:
1. **Organização dos Dados:**  
   Importação e estruturação de dados brutos, tratamento de inconsistências e aplicação de boas práticas de limpeza.
2. **Análise dos Dados:**  
   Exploração dos dados com técnicas básicas de estatística e lógica de negócio para entender padrões, tendências e oportunidades.
3. **Construção da Imagem:**  
   Escolha de gráficos e elementos visuais adequados para cada métrica (colunas, linhas, pizza, barras, mapas, etc.).
4. **Criação do Dashboard:**  
   Integração visual com segmentações (slicers), menus, filtros e layout limpo e funcional para facilitar a navegação.

## 💡 Ferramentas utilizadas
- Microsoft Excel
- Tabelas Dinâmicas
- Fórmulas e Funções
- Gráficos interativos
- Segmentações e Filtros
- Limpeza e tratamento de dados
